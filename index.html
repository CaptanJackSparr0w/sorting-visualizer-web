Quick Sort

Divide & Conquer
Best: O(n log n)
Average: O(n log n)
Worst: O(n²)
Space: O(log n)
Stable: No

Quick Sort is an efficient, in-place, divide-and-conquer sorting algorithm. It works by selecting a 'pivot' element from the array and partitioning the other elements into two sub-arrays according to whether they are less than or greater than the pivot.

Pseudocode / Core Implementation
// Quick Sort Partitioning Step
function quickSort(arr, low, high) {
  if (low < high) {
    let pi = partition(arr, low, high);
    quickSort(arr, low, pi - 1);
    quickSort(arr, pi + 1, high);
  }
}
